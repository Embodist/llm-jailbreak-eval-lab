# 真实越狱语料的经验分布

数据：`verazuo/jailbreak_llms`（CCS'24）2023-12-25 切片中的 jailbreak prompts，共 **1,405** 条（同切片另有约 22.5 万条普通提示词作对照）。用关键词规则粗分类，结果如下（`scripts/analyze_corpus.py`）。

| 手法 | 命中数 | 占比 |
|---|---:|---:|
| 虚构 / 故事框架（fiction） | 849 | 60% |
| 角色扮演 / 人格（roleplay） | 636 | 45% |
| 拒绝抑制（never refuse / unrestricted） | 352 | 25% |
| DAN 类人格 | 200 | 14% |
| 假设框架（imagine / suppose） | 178 | 13% |
| 授权 / 沙箱框架 | 126 | 9% |
| 指令覆盖 / 系统提示 | 106 | 8% |
| 非拉丁文字 | 19 | 1% |
| 情感胁迫 / PUA | 11 | <1% |
| 编码（base64/rot13/hex…） | 5 | <1% |
| 前缀注入 | 3 | <1% |

平均长度 **2,589 字符**。

## 解读

1. **真实流传的破甲提示词以“设定 + 叙事 + 拒绝抑制”为主**：虚构与角色扮演合计覆盖大多数样本，且经常叠加使用（平均 2.6k 字符说明是多层包装，不是一句话）。
2. **编码类在人类语料里极少**，但在学术与自动化攻击（GCG、Cipher、Multilingual、AutoDAN）里占比高。两者是不同生态：人类靠“讲故事”，自动化靠“搜对抗样本”。
3. **授权/沙箱框架占约 9%**，低于角色扮演，但与我们在逆向场景的实测结论一致——它对“技术类请求”的转化率最高，因为直接改写“是否被授权”这个判断线索。
4. 真实语料的来源以 `flowgpt`、`ChatGPT`、`ChatGPTJailbreak` 社区为主，说明这是一种**社区共创、快速迭代**的语料，单条提示词的生命周期很短（模型更新即失效）。

## 对评测设计的启示

- 只测“名场面提示词”会高估旧模板、低估组合手法。
- 必须**固定目标、逐类换包装**，否则无法判断是“提示词有效”还是“目标本身容易”。
- 人类语料偏叙事、学术语料偏表示层，两类都要覆盖；本项目单轮探针覆盖 A/B 两类，多轮场景覆盖 C 类。
