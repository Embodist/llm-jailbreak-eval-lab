# Frontend data

- `results.json` — generated by `scripts/export_frontend_data.py`. Contains
  aggregate rates, labels, technique/model IDs and short reasons. Safe to
  publish; no raw harmful prompts or model replies.
- `cases.json` — generated by `scripts/export_cases.py`. Contains the full
  reproduction prompts (system/user/prefill/turns). **Excluded from git** and
  served only by the server-side `/api/cases` route. Run `make cases` locally.

The dashboard still renders without `cases.json`; the 复现 tab will show a
message asking you to generate it.
